# ✿ Somewhere Online

*A little corner of the internet for curious minds.*

Somewhere Online is a nostalgic, scrapbook-inspired discovery website designed to showcase interesting finds from around the web, including websites, creative projects, digital experiences, and more.

## ✧ Preview



## ✧ Features

- **Hero Section** — Welcoming introduction with a discovery call to action.
- **Navigation Header** — Navigation links to the website sections.
- **Discovery Marquee** — Continuously scrolling collection of discoveries, with pause-on-hover functionality.
- **FAQ Section** — Interactive accordion for frequently asked questions.
- **Website Footer** — Navigation links, social links, and project information.

## ✧ Technologies

- HTML5
- CSS3
- JavaScript
- Git & GitHub

## ✧ Getting Started

Clone the repository:

```bash
git clone https://github.com/lumine404/Somewhere-Online
```

Navigate to the project directory:

```bash
cd somewhere-online
```

Open `index.html` in your browser.
